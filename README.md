# Jogo-RPG-de-Caíque
Jogo RPG de Caíque: Estratégia Militar Avançada Simulação estratégica profunda. Gerencie a BaseMilitar, recursos (Ouro, Éter) e tecnologia ramificada. O ProtocoloDeIA oferece análises de risco. Recrute Personagem com habilidades detalhadas e Afinidade (Harém/Romance) para aprimorar a Força Bélica. Seinen/Fantasia/Drama.
