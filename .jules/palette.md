## 2024-05-15 - Standardizing CLI Visuals
**Learning:** For CLI applications, raw data structures (like dictionaries) are poor UX. Implementing a reusable `exibir_painel` function with context-aware semantic color coding (Red for health, Yellow for resources, Green for power, Blue for status) significantly improves readability and user delight.
**Action:** Always prefer `exibir_painel` over direct prints of dictionaries in the main loop or demo blocks.
