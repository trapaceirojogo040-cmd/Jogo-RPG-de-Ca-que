## 2025-05-14 - Reusable CLI Panel Pattern
**Learning:** In CLI applications, displaying raw dictionaries is a poor UX. A reusable `exibir_painel` function with hierarchical nesting and themed color coding (Red for health, Yellow for resources, etc.) significantly improves readability and provides a "delightful" interface even without a GUI.
**Action:** Use a similar `exibir_painel` pattern for any CLI tool that needs to display structured configuration or state data.
