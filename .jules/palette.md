## 2025-01-24 - Structured CLI Data Visualization
**UX Issue:** Raw dictionary output in CLI is hard to read and lacks hierarchy.
**Learning:** Color-coded, structured panels improve scanability and user focus.
**Prevention:** Implement a reusable `exibir_painel` function with themed ANSI colors (e.g., Red for health, Yellow for resources) to present game state clearly.
