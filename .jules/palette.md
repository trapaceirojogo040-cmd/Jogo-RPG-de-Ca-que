# Palette's Journal

This journal is for CRITICAL UX/accessibility learnings only.

## 2024-05-23 - Padronização de Cores e Exibição de Dados no CLI
**Learning:** Hardcoding de códigos ANSI dificulta a manutenção e a consistência visual. O uso de uma classe de constantes melhora a legibilidade.
**Pattern:** Implementação do `exibir_painel` com preenchimento (padding) dinâmico garante que os dados estejam sempre alinhados, independentemente do tamanho das chaves.
**Color Scheme:** Vermelho para vida, Amarelo para recursos, Verde para níveis/poder e Azul para status/rede.
