## 2025-05-15 - Reusable CLI Data Presentation
**UX Issue:** Raw dictionary printing in the CLI makes information difficult to scan and parse.
**Learning:** Decoupling data retrieval from presentation allows for consistent, themed, and accessible UI patterns.
**Prevention:** Implement a standard `exibir_painel` function that uses ANSI colors and structured formatting to present game data (stats, base status) clearly to the user.
